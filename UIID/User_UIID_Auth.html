📋 UIID 등록 규칙
모든 사용자(국가, 기구, 회사, 조직, 개인 등)는 User Code 1개를 기본 등록할 수 있습니다.
User Code는 이름 6자리 + 협업 2자리입니다. 이름 6자리는 한 사람만 쓸 수 있고, 한 번 정하면 바꿀 수 없습니다.
국가명·국가 약자·유명 기업과 기관 이름·숫자만 6자리·같은 글자 6개 등은 예약되어 있습니다. 단체·기관 등록은 선등록 신청 후 심사를 거쳐 허가됩니다.
이메일 인증(또는 Google 계정)을 마친 본인만 User Code를 정할 수 있습니다.
FFFFFFFF은 국제 긴급문자 통보 UIID로 확보되어 있습니다.
💛 UIID(세계정보식별코드)는 AI의 진실응답 운동을 위하여 무상 제공됩니다.
